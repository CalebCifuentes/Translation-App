# Translation-App
This is the README for our CSC 450 project. This is a ios translation app, at the moment we are using react native for the frontend, node js for the backend,
python for the NLP pipeline. We will use faster-whisper for transcription, smartcat API for MVP, PyTorch + Hugging Face for the small model
and puter.js or similar text to speech api for voice synthesis. The app should first launch and ask permission for microphone access on first use.​
Then the user chooses the source languages​ speak, with a single tap of a button the process starts.​ Translated audio is played back quickly.
Converstation should flow naturally.
